# CHECKLIST PIXEL

## Avant le premier build

- [ ] J'ai un compte GitHub.
- [ ] Mon dépôt NOVA est privé.
- [ ] `app/` est bien à la racine.
- [ ] `.github/workflows/android-build.yml` existe.
- [ ] `gradlew` existe à la racine.
- [ ] J'ai fait un commit.

## Pour récupérer l'application

- [ ] GitHub → Actions.
- [ ] Le build est vert.
- [ ] J'ouvre le dernier build.
- [ ] Je télécharge l'Artifact APK.
- [ ] Je décompresse si nécessaire.
- [ ] J'installe `app-debug.apk`.

## Si c'est rouge

Copie-moi simplement :
- le nom de l'erreur ;
- les dernières lignes rouges ;
- ou une capture d'écran.

Je corrige le projet avec toi.
