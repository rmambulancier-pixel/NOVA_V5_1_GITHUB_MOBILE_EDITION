# 📱 NOVA V5.1.1 — ONE CLICK MOBILE

## Objectif

**Créer et installer NOVA depuis ton Pixel, sans ordinateur.**

## 🚀 Le chemin le plus simple

### 1️⃣ Crée un dépôt GitHub

- Ouvre GitHub sur ton Pixel.
- Appuie sur `+`.
- `New repository`.
- Nom : `NOVA`.
- Mets-le en **Private**.
- Crée le dépôt.

### 2️⃣ Envoie le contenu de ce ZIP

Décompresse le ZIP sur ton Pixel.

Important : envoie **le contenu du dossier NOVA**, pas le ZIP dans un sous-dossier.

À la racine du dépôt tu dois voir :

- `app`
- `.github`
- `settings.gradle.kts`
- `build.gradle.kts`
- `gradlew`

### 3️⃣ Attends

Dès que GitHub reçoit les fichiers :

**Actions → NOVA • ONE CLICK APK**

La compilation démarre.

### 4️⃣ Quand c'est vert 🟢

Ouvre le build terminé.

Descends jusqu'à :

**Artifacts**

Télécharge :

`NOVA-ONE-CLICK-APK-XX`

### 5️⃣ Installe l'APK

Sur ton Pixel :

- ouvre le téléchargement ;
- autorise l'installation si Android le demande ;
- installe NOVA.

# 😈 Ton quotidien ensuite

Tu me dis simplement :

> "Je veux ajouter X."

Je te prépare les fichiers modifiés.

Tu les remplaces sur GitHub.

Tu fais un commit.

**GitHub fabrique automatiquement la nouvelle APK.**
